# ⚡ Quick Start - 5 Minutos

## 1️⃣ Instalar

```bash
npm install
```

## 2️⃣ Configurar

Edite o arquivo `.env`:
- Adicione seu email do Gmail (com Senha de Aplicativo)
- Adicione dados da Twilio (WhatsApp) - opcional por enquanto

```env
SMTP_USER=seu-email@gmail.com
SMTP_PASS=senha-app-do-gmail
```

## 3️⃣ Rodar

```bash
npm run dev
```

## 4️⃣ Acessar

Abra no navegador: **http://localhost:5000**

## 5️⃣ Testar

1. Adicione um produto ao carrinho (clique +)
2. Clique em 🛒 Carrinho
3. Clique em "Finalizar Pedido"
4. Preencha o formulário (use seu email real)
5. Escolha como receber: WhatsApp, Email ou Ambos
6. Clique em "Confirmar Pedido"

## ✅ Pronto!

Seu e-commerce está rodando! 🎉

---

## 🚀 Deploy em 2 minutos

1. Acesse: **https://vercel.com**
2. Clique em **Add New Project**
3. Selecione a pasta `JK-ARTIGOS`
4. Adicione variáveis de ambiente (. env)
5. Clique em **Deploy**

Seu site estará em: `https://seu-projeto.vercel.app`

Compartilhe o link nas redes sociais! 📱

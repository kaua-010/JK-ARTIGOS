✏️ PASSO 3: RENOMEAR FOTOS

  biblia-[COR]-2.jpg    ← Lateral/outro ângulo
  biblia-[COR]-3.jpg    ← Aberta/interior
  biblia-[COR]-4.jpg    ← Detalhe especial

🎬 PASSO 4: COMO RENOMEAR NO WINDOWS
═══════════════════════════════════════════════════════════════

MÉTODO 1 - Renomear uma por uma (mais fácil):

1. Clique com direito na imagem
2. Selecione "Renomear"
3. Digite o novo nome
4. Pressione ENTER
5. Repetir para as próximas

Exemplo:
  WhatsApp Image 2026-04-07 at 17.30.42 (1).jpeg
  → Clique direito → Renomear
  → Digite: biblia-preta-1.jpg
  → ENTER ✓


MÉTODO 2 - Script automático (mais rápido):

Se tem EXATAMENTE 32 imagens (8 produtos × 4 fotos):

1. Abra PowerShell na pasta
2. Cole este script:

---
$produtos = @(
  "preta", "nvi", "rosa", "ara", "gigante", "dourada", "compacta", "lilas"
)

$arquivos = Get-ChildItem -Filter "*.jpeg" | Sort-Object

$i = 0
foreach ($arquivo in $arquivos) {
  $produtoIdx = [math]::Floor($i / 4)
  $fotoIdx = ($i % 4) + 1
  $produto = $produtos[$produtoIdx]
  
  $novoNome = "biblia-$produto-$fotoIdx.jpg"
  Rename-Item -Path $arquivo.FullName -NewName $novoNome
  
  Write-Host "$($arquivo.Name) → $novoNome"
  $i++
}
---

3. Pressione ENTER
4. Pronto! Todas renomeadas! ✓

❓ DÚVIDAS
═══════════════════════════════════════════════════════════════

P: Quantas fotos preciso de cada produto?
R: Mínimo 1, recomendado 4

P: Qual extensão? .jpg, .jpeg, .png?
R: Qualquer uma funciona (.jpg é melhor)

P: Posso adicionar 5 fotos de um produto?
R: Sim! Use biblia-preta-5.jpg, biblia-preta-6.jpg, etc

P: A ordem das fotos importa?
R: Sim! A ordem determinada qual aparece primeiro

P: Não consegui renomear via script?
R: Renomeie uma por uma com clique direito (mais lento mas funciona)
